显示最近的 git 提交历史。

提交数量: $ARGUMENTS (未指定时默认: 5)

## 步骤

1. 运行 `git log --oneline -n [数量]`
2. 提供简要摘要

## 输出格式

```
## 最近提交

| 哈希 | 信息 | 作者 | 时间 |
|------|---------|--------|------|
| abc123 | feat: 添加登录功能 | 张三 | 2小时前 |
| def456 | fix: 修复空值检查 | 李四 | 5小时前 |
...

### 摘要
- 总计: 显示了 [n] 个提交
- 最活跃: [最频繁的提交类型]
- 最近重点: [最近的工作似乎是关于什么]
```

保持简洁易读。
