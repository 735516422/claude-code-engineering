显示当前 git 状态及帮助性上下文。

## 步骤

1. 运行 `git status`
2. 以友好的格式总结状态

## 输出格式

```
## Git 状态

分支: [分支名称]
状态: [干净 / 有更改 / 有冲突]

### 已暂存的更改（准备好提交）
- [文件]

### 未暂存的更改（未暂存）
- [文件]

### 未跟踪的文件
- [文件]

### 建议的下一步
- [您接下来可能想做的事情]
```

如果仓库是干净的，只需显示:
```
✓ 工作树在分支 [名称] 上是干净的
```
